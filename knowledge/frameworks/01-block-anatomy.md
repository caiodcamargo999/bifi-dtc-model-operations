# Anatomia de Blocos — a gramática de copy DR

Todo ad de resposta direta (VSL, long text, advertorial) é uma sequência de **blocos funcionais**.
Cada bloco tem UMA função persuasiva. Escrever copy = escolher a sequência de blocos e preenchê-los.

Esta taxonomia foi extraída da engenharia reversa de 5 ads validados (ver `reference/crowned/`).
**Nunca escreva copy livre. Escreva blocos rotulados.** O rótulo vai no output, acima da linha.

---

## Inventário de blocos

### Abertura (0–5s / primeiras 2 linhas)

| Bloco | Função | Regra |
|---|---|---|
| `HOOK` | Parar o scroll | ≤2 frases. Ver `03-hooks.md` |
| `HOOK 2` | Variante de teste do mesmo ângulo | Sempre entregue H1 + H2 por ad |
| `QUALIFICAÇÃO VISUAL` | "Se seu X está assim, isso é pra você" | Filtra o público na cara |
| `COMANDO DE ATENÇÃO` | "Fica até o final", "Presta atenção" | Só funciona colado em prova |

### Construção do problema

| Bloco | Função |
|---|---|
| `ABERTURA — PROVA PESSOAL` | Narradora se posiciona como igual, não vendedora |
| `HISTÓRIA EMOCIONAL` | O momento concreto em que o problema virou real |
| `CONSTRUÇÃO DO PROBLEMA` | Escalada: sintoma → frequência → permanência |
| `CONSEQUÊNCIAS EMOCIONAIS` | Perda de identidade. **Não é sintoma, é quem ela deixou de ser** |
| `PONTO DE DESESPERO` | "Já tinha tentado tudo, não tinha nada a perder" — libera a compra |
| `ACEITAÇÃO FALSA` | "Comecei a acreditar que era só aceitar" — prepara a virada |

### Invalidação (mata a concorrência)

| Bloco | Função |
|---|---|
| `INVALIDANDO SOLUÇÕES` | Lista o que ela já tentou, por nome |
| `INVALIDANDO SOLUÇÃO ESPECÍFICA` | Uma solução dominante + suas consequências reais |
| `INVESTIMENTO PERDIDO` | "$X gastos" — quantifica a dor e ancora valor |
| `INIMIGO COMUM` | Indústria / médicos / marcas bilionárias |

> **Regra de invalidação:** cada solução invalidada tem que fechar uma *saída lógica*.
> Não liste concorrentes. Liste as saídas que a prospect usaria pra não comprar.

### Virada mecânica (o coração)

Sequência obrigatória, **nesta ordem**:

1. `TRANSIÇÃO PRA SOLUÇÃO` — agente externo credível (nova dermatologista, cabeleireira, amiga, artigo)
2. `SPOILER DA CAUSA RAIZ` — "o problema todo se resume a..."
3. `NOMEAÇÃO DO MUP` — batiza o vilão (Mecanismo Único do Problema). Nome próprio, memorável
4. `EXPLICAÇÃO DO MECANISMO DO PROBLEMA` — cadeia causal em 3–5 passos curtos
5. `SPOILER DO MECANISMO DA SOLUÇÃO` — "ao bloquear/reativar X, ..."
6. `APRESENTAÇÃO DA SOLUÇÃO 2.0` — o nome do ritual/sistema, **não o nome do produto**
7. `SIMPLICIDADE DO MÉTODO` — "20 segundos toda manhã"

> **Solução 2.0:** em afiliado/advertorial, a copy vende um *método nomeado* ("Anti-Shed Morning Ritual"),
> não o SKU. O produto aparece na página, não no ad. Isso reduz rejeição e sobrevive a review de plataforma.

### Prova

| Bloco | Função |
|---|---|
| `PROVA DEMONSTRATIVA — ANTES` | Estado inicial, concreto e visual |
| `PROVA DEMONSTRATIVA — DEPOIS` | Estado final |
| `PROVA PESSOAL + TIMELINE` | **Marcos datados**: dia 5, semana 2, dia 20, 2 meses |
| `PROVA SOCIAL` | Terceiro valida (marido, irmã, cabeleireira, volume de perguntas) |
| `CETICISMO SUPERADO` | "Parece loucura, né? Foi o que eu pensei também" |
| `HONESTIDADE` | "Semana 1: nada aconteceu. Não sou vendedora." — **o bloco de maior ROI de confiança** |

> **Timeline é o bloco mais subestimado.** Ele faz duas coisas ao mesmo tempo: prova e controle de
> expectativa. A prospect que sabe que semana 1 não muda nada não pede reembolso na semana 2.

### Fechamento

| Bloco | Função |
|---|---|
| `REASON WHY DO VÍDEO` | Por que ela está gravando — missão pessoal, não venda |
| `TRANSIÇÃO PRO ARTIGO` | Delegação de autoridade: "o artigo explica melhor que eu" |
| `QUEBRA DE OBJEÇÕES — PREÇO` | "Paguei $180 por isso, deixo de graça" |
| `DESINTERESSE FINANCEIRO` | "Não ganho nada com esse vídeo" |
| `ESCASSEZ` | O artigo pode sair do ar / vazou / é temporário |
| `CTA DIRETO` | Um verbo, um botão, uma ação |
| `REFRAME` | Quebra de crença final: "você não precisa viver com isso" |
| `CTA FINAL` | Repetição curta + urgência |

## Estruturas de referência (sequências validadas)

**A. Transformação pessoal** (mais usada, melhor Hook Rate)
```
HOOK → PROVA DEMONSTRATIVA ANTES → ABERTURA PROVA PESSOAL → HISTÓRIA EMOCIONAL →
CONSEQUÊNCIAS EMOCIONAIS → INVALIDANDO SOLUÇÕES → PONTO DE DESESPERO →
TRANSIÇÃO PRA SOLUÇÃO → SPOILER CAUSA RAIZ → NOMEAÇÃO DO MUP →
MECANISMO DO PROBLEMA → MECANISMO DA SOLUÇÃO → SOLUÇÃO 2.0 →
PROVA PESSOAL + TIMELINE → PROVA SOCIAL → REASON WHY → TRANSIÇÃO PRO ARTIGO →
QUEBRA DE OBJEÇÕES → CTA DIRETO → ESCASSEZ → CTA FINAL
```

**B. Teste/experimento** (melhor Body Rate — o loop segura)
```
HOOK (ceticismo) → SETUP DO TESTE (medida dia 0) → TIMELINE SEMANA 1 (HONESTIDADE: nada) →
TIMELINE SEMANA 4 → TIMELINE SEMANA 6 → TIMELINE SEMANA 8 (resultado) →
DESAFIO AO LEITOR → HISTÓRIA EMOCIONAL → INVALIDANDO SOLUÇÕES →
TRANSIÇÃO PRA SOLUÇÃO → SOLUÇÃO 2.0 → MECANISMO DA SOLUÇÃO →
ESCASSEZ → CTA DIRETO → INIMIGO COMUM → CTA FINAL
```

**C. Reframe científico** (para avatar resignado/cético — desmonta crença antes de ofertar)
```
HOOK (invalidação de crença) → NOMEAÇÃO DO MUP → MECANISMO DO PROBLEMA →
INVALIDANDO SOLUÇÕES (por que TODAS falharam pelo mesmo motivo) →
A FALHA COMUM (delivery/absorção/dose) → MECANISMO DA SOLUÇÃO →
SOLUÇÃO 2.0 → TIMELINE → CTA
```

**D. Comparativa** (para quem já usa a solução dominante)
```
HOOK (a armadilha da solução atual) → CUSTO REAL DA SOLUÇÃO ATUAL →
POR QUE ELA FUNCIONA MAS APRISIONA → A TERCEIRA OPÇÃO →
DIFERENÇA DE MECANISMO (não de promessa) → TIMELINE → CTA
```

## Regras invioláveis

1. **Um bloco, uma função.** Bloco que faz duas coisas não faz nenhuma.
2. **A ordem da virada mecânica é fixa.** Nomear o MUP antes de explicar o mecanismo mata a curiosidade.
3. **Nunca invalide sem oferecer saída.** Invalidação sem mecanismo alternativo = desespero, não compra.
4. **Prova antes de promessa.** Toda promessa precisa de um bloco de prova a ≤2 blocos de distância.
5. **A `CONSEQUÊNCIA EMOCIONAL` é identitária, não sintomática.** Não "meu cabelo caiu" — "parei de aparecer em fotos".
6. **CTA nunca aparece antes da `QUEBRA DE OBJEÇÕES`.** Pedir a ação com objeção viva queima o clique.
